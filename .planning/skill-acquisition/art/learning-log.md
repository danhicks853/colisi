## 2026-05-12 — Session 03: Phase 1.2 — Light + value (sphere studies)

- **Syllabus phase / module:** Phase 1.2 — Light + value for cel-shading.
- **Goal:** Build the eye for the six light regions on a sphere across 5 lighting scenarios; articulate where cel-shading bands would fall.
- **Tooling decision:** Daniel chose iPad + Procreate (graphite-style brushes, grayscale) over pencil + paper. Syllabus authorized this path. Apple Pencil Gen 2 with pressure confirmed working.
- **What was built:** 6 sphere studies (5 scenarios; overhead scenario was iterated twice as the "no outline" lesson landed). Saved in `art-scratch/01-foundations/spheres/`. Studies progressed:
  - **Study 1 (overhead):** outlined circle; no cast shadow; no highlight. Foundational issue identified — drawing the *symbol of a sphere* (2D circle) instead of the *3D form*.
  - **Study 2 (overhead, redo):** outline gone; cast shadow added; broader value range. Core "see form not outline" lesson landed in one iteration.
  - **Study 3 (cool side rim, left):** highlight added (but too large); cast shadow direction correct; value range strong.
  - **Study 4 (warm-cool split, L+R):** highlight compressed to proper size (small specular peak); terminator captured (drawn slightly too crisply — terminators are *bands* not *lines*); two-light interaction visible with one dominant + one fill.
  - **Study 5 (overcast diffuse):** value range correctly compressed; ambient occlusion at top/bottom correctly subtle; NO fake contrast added. Lesson: trust observation, don't fabricate cues that aren't there.
  - **Study 6 (golden-hour rake, light below):** long dramatic cast shadow; all six regions labeled; band-placement articulated for 2-band and 3-band cel-shading.
- **Technique learned:**
  - Edges of forms are **value transitions, not lines.** Outlines flatten the form.
  - Six light regions: cast shadow, form shadow, terminator, half-tone, light, highlight.
  - Highlight is a *peak* (small specular point), not a *region*.
  - Terminator is a *band* (narrow densest region), not a *line*.
  - Contact shadow (sphere meets surface) is typically the darkest spot in any scene.
  - Diffuse light = compressed value range; resist fabricating contrast.
  - **2-band cel:** boundary at terminator (lit = highlight+light+half-tone; shadow = terminator+form-shadow+cast-shadow).
  - **3-band cel:** highlight+light → bright; half-tone → mid; terminator+form-shadow+cast-shadow → shadow.
  - **Colisi style note:** hard band edges (not soft gradients between bands) + painterly accent overlay layer = the synthesis. Half-tone band width is per-asset (narrow = graphic/Hades; wide = dimensional/Ghibli).
- **Style-direction checks:** Band-placement choices map cleanly to cel-shading pipeline in Phase 2.2/2.3. Foundation for every shaded surface in the project established.
- **AI policy notes:** All studies by Daniel. Claude critiqued per study; identified observation patterns + recurring issues (outline reflex, highlight size, terminator-as-line); never proposed specific value placements.

## 2026-05-12 — Session 05: Phase 2.1 — Blender Guru donut tutorial

- **Syllabus phase / module:** Phase 2.1 — Blender Guru donut tutorial (full series).
- **Goal:** Trial-by-fire of Blender's whole interface in one project; full pipeline tour from modeling to render.
- **What was built:** Complete donut + icing + sprinkles + plate + scene + Cycles render. Saved at `D:\Projects\art-scratch\02-blender-fundamentals\donut.blend`. Final render shows working material system (translucent icing, matte plate, wood grain), working particle system (sprinkle distribution), grounded lighting/shadow.
- **Technique learned:**
  - **Edit Mode** = vertex/edge/face manipulation (vs. Object Mode = whole-object transforms).
  - **Modifier** = non-destructive effect in a stack; can be edited or removed without altering base mesh. Named instances: subdivision, solidify, shrinkwrap. *(Solidify is the modifier used for ink-outline in Phase 2.2.)*
  - **Shader / material** = recipe controlling surface appearance via parameters (color, roughness, metallic, etc.); built in Shader Editor via node connections.
  - **UV unwrap** = separate process from shader; lays out 3D mesh as flat 2D canvas (like peeling an orange and flattening the peel). Bridges 3D surface to 2D texture work.
  - **Particle system** = scatter/distribute objects across a surface (sprinkles on the icing).
  - **Cycles renderer** = path-traced realistic renderer used for donut. Colisi will switch to **Eevee** (realtime rasterized renderer) from Phase 2.2 onward per STACK.md target (modest-hardware audience). Cel-shading uses Eevee-specific **Shader-to-RGB node**.
- **Style-direction checks:** N/A — donut tutorial is intentionally photoreal-leaning, not stylized. Aesthetic alignment begins at Phase 2.2.
- **AI policy notes:** No creative content authored. Tutorial completion + concept articulation only.
- **Phase 2.1 status:** ✅ Complete.
