## Reference deck rules (project policy — citation, not creative content)

Per `D-STYLE-02` + `PHILOSOPHY.md` §V + `AI-DISCLOSURE.md`:

1. **Human-curated only.** Daniel and Dawn add references; Claude does not propose references, mood words, or palette directions.
2. **Zero AI-generated reference art.** Even for personal reference. Per `PHILOSOPHY.md` §III production guardrail: *"Concept art / mood boards / reference art — even if never shipped"* are forbidden as AI-generated. This is not a debatable rule.
3. **License / attribution tracking.** Every reference cites its source and licensing status. References are for **inspiration** — none are used as final assets unless their license explicitly permits.
4. **No links to AI-art generators.** No Midjourney mood boards. No Stable Diffusion outputs. No DALL-E reference. The cozy community has hardened against AI art (per `PHILOSOPHY.md` §V); there is no version of this where AI-generated reference is acceptable.
5. **Append-only catalog.** When references are removed (e.g., a license changes), strike-through with date and reason. Do not silently delete.
